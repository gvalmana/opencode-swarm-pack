# Roadmap

Future work should remain incremental and OpenCode-first, then be documented for Codex, Copilot, and Claude Code parity.

## Planned

- `security-team`: compose `swarm-reviewer`, `swarm-security-reviewer`, and a future dependency/license auditor.
- Dependency and license auditor role for package-manager-specific risk checks.
- Docs writer role for README, CHANGELOG, migration notes, and user-facing documentation.

## Deferred

- Full canonical `swarm/` model and renderer pipeline.
- Release manager role and release-team workflow.
- Performance, database migration, UX, and observability reviewers.
