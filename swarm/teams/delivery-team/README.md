# Delivery Team

This is the initial canonical scaffold for the delivery workflow. It documents the portable model only; the functional OpenCode assets still live under `teams/delivery-team/`.

The canonical team definition is intentionally free of OpenCode-specific frontmatter such as `mode`, `permission`, and `agent`.

Current workflow:

```text
coder -> cleaner -> final
```

Future work should add portable role, workflow, and skill definitions under this folder, then teach target renderers how to transform them into native files.
